AI actions inside each page

The problem

Madeline offered the same three suggestions on every page, with no icon, so it never felt like she knew where you were.

What changed

Each page now has its own actions, using the exact names from your spec:

What a good AI answer looks like

  • Answer first, short: one summary sentence, then 2 to 4 bullets. No essays.
  • Shows its sources: small chips like "4 meetings · 2 tasks". Clicking one opens that page.
  • Ends with a next step: buttons such as "Draft follow-up to Bruce" turn the answer into action in one click.
  • Asks before acting: sending an email, creating a task or booking time always needs your click.
  • 👍 / 👎 on every answer. Ratings are saved with the question and answer, so admins can see what to improve.
  • Conversation follows you to any device you sign in on.

Bugs found while testing

  • Adding events to Google Calendar never worked. The Google sign-in asked for "view" permission only. It now asks for "view and edit events", and a test event was created successfully.
  • "Plan this day" was refused as off-topic because the calendar held personal events (Miracle Morning, Bible Study). Madeline's own buttons now always go through.
  • Calendar event descriptions showed raw code. They now show as a proper list.
  • The Dashboard's "Meetings today" counted every meeting on file, not just today's. It now matches Madeline.
  • Drafts were wordy. Follow-up drafts now name the real task they're based on, in 3 to 5 sentences, without filler.
